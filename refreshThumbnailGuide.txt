# 🔄 `/refresh-thumbnail` Endpoint - Frontend Integration Guide

## 📋 **Overview**

The `/refresh-thumbnail` endpoint automatically refreshes expired TikTok thumbnail URLs and optionally updates your stored data. It's designed to solve the problem of TikTok's temporary/signed URLs that expire after a few hours.

## 🚀 **Quick Start**

### **Basic Usage (No Database Update)**
```javascript
const response = await fetch('/refresh-thumbnail', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://www.tiktok.com/@user/video/123456789'
  })
});

const data = await response.json();
console.log(data.thumbnailURL); // Fresh thumbnail URL
```

### **With Database Update**
```javascript
const response = await fetch('/refresh-thumbnail', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://www.tiktok.com/@user/video/123456789',
    user_id: 'your_user_id_here'
  })
});

const data = await response.json();
console.log(data.thumbnailURL); // Fresh thumbnail URL
console.log(data.updated_stored_data); // true if database was updated
```

## 📡 **API Reference**

### **Endpoint**
```
POST /refresh-thumbnail
```

### **Request Body**
```typescript
{
  url: string;           // Required: TikTok video/slideshow URL
  user_id?: string;      // Optional: User ID for database updates
}
```

### **Response**
```typescript
{
  thumbnailURL: string;           // Fresh thumbnail URL (permanent or temporary)
  updated_stored_data: boolean;   // Whether database update was attempted
}
```

### **Error Response**
```typescript
{
  error: string;  // Error message
}
```

## �� **Use Cases**

### **1. Automatic Thumbnail Refresh**
When you detect a broken thumbnail image in your UI:

```javascript
async function refreshBrokenThumbnail(tiktokUrl) {
  try {
    const response = await fetch('/refresh-thumbnail', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ url: tiktokUrl })
    });
    
    const data = await response.json();
    
    if (data.thumbnailURL) {
      // Update your UI with the fresh thumbnail
      updateThumbnailInUI(tiktokUrl, data.thumbnailURL);
      return data.thumbnailURL;
    }
  } catch (error) {
    console.error('Failed to refresh thumbnail:', error);
  }
}
```

### **2. Proactive Thumbnail Updates**
Update thumbnails for all user's TikTok videos:

```javascript
async function refreshAllUserThumbnails(userId, tiktokUrls) {
  const results = [];
  
  for (const url of tiktokUrls) {
    try {
      const response = await fetch('/refresh-thumbnail', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ 
          url: url, 
          user_id: userId 
        })
      });
      
      const data = await response.json();
      results.push({
        url: url,
        success: !!data.thumbnailURL,
        newThumbnail: data.thumbnailURL,
        updated: data.updated_stored_data
      });
    } catch (error) {
      results.push({
        url: url,
        success: false,
        error: error.message
      });
    }
  }
  
  return results;
}
```

### **3. Image Error Handling**
Handle broken images automatically:

```javascript
function setupThumbnailErrorHandling() {
  // Listen for image load errors
  document.addEventListener('error', async (event) => {
    if (event.target.tagName === 'IMG' && event.target.dataset.tiktokUrl) {
      const tiktokUrl = event.target.dataset.tiktokUrl;
      
      // Try to refresh the thumbnail
      const newThumbnailUrl = await refreshBrokenThumbnail(tiktokUrl);
      
      if (newThumbnailUrl) {
        // Update the broken image
        event.target.src = newThumbnailUrl;
      }
    }
  }, true);
}
```

## 🔧 **Integration Examples**

### **React Component**
```jsx
import React, { useState, useEffect } from 'react';

function TikTokThumbnail({ url, user_id }) {
  const [thumbnailUrl, setThumbnailUrl] = useState(null);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  const refreshThumbnail = async () => {
    setLoading(true);
    setError(null);
    
    try {
      const response = await fetch('/refresh-thumbnail', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ url, user_id })
      });
      
      const data = await response.json();
      
      if (data.thumbnailURL) {
        setThumbnailUrl(data.thumbnailURL);
      } else {
        setError('Failed to get thumbnail');
      }
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  };

  const handleImageError = () => {
    // Automatically refresh when image fails to load
    refreshThumbnail();
  };

  return (
    <div>
      {thumbnailUrl && (
        <img 
          src={thumbnailUrl} 
          alt="TikTok thumbnail"
          onError={handleImageError}
          style={{ opacity: loading ? 0.5 : 1 }}
        />
      )}
      
      {loading && <div>Refreshing thumbnail...</div>}
      {error && <div>Error: {error}</div>}
      
      <button onClick={refreshThumbnail} disabled={loading}>
        Refresh Thumbnail
      </button>
    </div>
  );
}
```

## ⚡ **Performance Tips**

### **1. Batch Updates**
Instead of refreshing thumbnails one by one, consider batching them:

```javascript
async function batchRefreshThumbnails(userId, urls) {
  // Process in batches of 5 to avoid overwhelming the server
  const batchSize = 5;
  const results = [];
  
  for (let i = 0; i < urls.length; i += batchSize) {
    const batch = urls.slice(i, i + batchSize);
    const batchPromises = batch.map(url => 
      fetch('/refresh-thumbnail', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ url, user_id: userId })
      }).then(r => r.json())
    );
    
    const batchResults = await Promise.all(batchPromises);
    results.push(...batchResults);
    
    // Small delay between batches
    if (i + batchSize < urls.length) {
      await new Promise(resolve => setTimeout(resolve, 1000));
    }
  }
  
  return results;
}
```

### **2. Caching**
Cache successful thumbnail URLs to avoid unnecessary requests:

```javascript
const thumbnailCache = new Map();

async function getCachedThumbnail(url, userId) {
  const cacheKey = `${url}_${userId || 'anonymous'}`;
  
  // Check cache first
  if (thumbnailCache.has(cacheKey)) {
    const cached = thumbnailCache.get(cacheKey);
    if (Date.now() - cached.timestamp < 24 * 60 * 60 * 1000) { // 24 hours
      return cached.thumbnailUrl;
    }
  }
  
  // Refresh from server
  const response = await fetch('/refresh-thumbnail', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ url, user_id: userId })
  });
  
  const data = await response.json();
  
  if (data.thumbnailURL) {
    // Cache the result
    thumbnailCache.set(cacheKey, {
      thumbnailUrl: data.thumbnailURL,
      timestamp: Date.now()
    });
    
    return data.thumbnailURL;
  }
  
  return null;
}
```

## 🚨 **Error Handling**

### **Common Error Scenarios**
```javascript
async function handleThumbnailRefresh(url, userId) {
  try {
    const response = await fetch('/refresh-thumbnail', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ url, user_id: userId })
    });
    
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}: ${response.statusText}`);
    }
    
    const data = await response.json();
    
    if (data.error) {
      throw new Error(data.error);
    }
    
    return data.thumbnailURL;
    
  } catch (error) {
    // Handle different error types
    if (error.message.includes('No thumbnail found')) {
      console.warn('TikTok video has no thumbnail');
      return null;
    } else if (error.message.includes('Invalid TikTok URL')) {
      console.error('Invalid TikTok URL provided');
      return null;
    } else {
      console.error('Failed to refresh thumbnail:', error);
      return null;
    }
  }
}
```

## 📊 **Monitoring & Analytics**

Track thumbnail refresh success rates:

```javascript
async function refreshThumbnailWithAnalytics(url, userId) {
  const startTime = Date.now();
  
  try {
    const result = await fetch('/refresh-thumbnail', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ url, user_id: userId })
    });
    
    const data = await result.json();
    const duration = Date.now() - startTime;
    
    // Track analytics
    analytics.track('thumbnail_refresh', {
      success: !!data.thumbnailURL,
      duration,
      hasUserId: !!userId,
      updatedStoredData: data.updated_stored_data
    });
    
    return data.thumbnailURL;
    
  } catch (error) {
    const duration = Date.now() - startTime;
    
    analytics.track('thumbnail_refresh_error', {
      error: error.message,
      duration,
      hasUserId: !!userId
    });
    
    throw error;
  }
}
```

The `/refresh-thumbnail` endpoint provides:

- ✅ **Automatic thumbnail refresh** for expired TikTok URLs
- ✅ **Permanent storage** option to prevent future expirations
- ✅ **Database synchronization** to keep stored data up-to-date
- ✅ **Robust error handling** with multiple fallback strategies
- ✅ **Transparent integration** - no frontend changes required for basic usage

**The endpoint handles all the complexity of TikTok's temporary URLs, so your frontend can focus on displaying content without worrying about broken thumbnails!** 🚀
