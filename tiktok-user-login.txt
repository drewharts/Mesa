# TikTok OAuth Frontend Integration Guide

This guide explains how to implement TikTok OAuth authentication on the frontend to enable enhanced place data extraction from TikTok videos.

## Overview

The backend now supports TikTok OAuth which allows users to authorize your app to access their TikTok data. This provides access to exact POI (Point of Interest) data from videos, which is much more accurate than extracting locations from captions.

## Backend Endpoints Available

The following endpoints have been implemented:

### 1. Check TikTok Connection Status
```
GET /auth/tiktok/status
```
- **Purpose**: Check if current user has connected their TikTok account
- **Auth**: Requires user authentication
- **Response**:
```json
{
  "connected": true,
  "expires_at": "2024-01-15T10:30:00Z"
}
```

### 2. Initiate TikTok OAuth Flow
```
GET /auth/tiktok/login
```
- **Purpose**: Start OAuth process - redirects user to TikTok
- **Auth**: Optional (works for both authenticated and anonymous users)
- **Response**: HTTP redirect to TikTok authorization page

### 3. Handle OAuth Callback
```
GET /auth/tiktok/callback
```
- **Purpose**: TikTok redirects here after user authorization
- **Auth**: Optional
- **Response**:
```json
{
  "success": true,
  "message": "TikTok account connected successfully"
}
```

### 4. Disconnect TikTok Account
```
DELETE /auth/tiktok/disconnect
```
- **Purpose**: Remove TikTok authorization for user
- **Auth**: Requires user authentication
- **Response**:
```json
{
  "success": true,
  "message": "TikTok account disconnected"
}
```

### 5. Process URL with Authorization
```
POST /process-url-with-auth
```
- **Purpose**: Process TikTok URLs using user's token (gets exact POI data)
- **Auth**: Requires user authentication
- **Body**:
```json
{
  "url": "https://www.tiktok.com/@user/video/123456789"
}
```
- **Response**: Enhanced video data with POI information

## Frontend Implementation Steps

### Step 1: Check Connection Status

Before processing TikTok URLs, check if the user has connected their account:

```javascript
async function checkTikTokStatus() {
  try {
    const response = await fetch('/auth/tiktok/status', {
      method: 'GET',
      credentials: 'include',
      headers: {
        'Authorization': `Bearer ${userToken}` // Your Firebase auth token
      }
    });
    
    if (response.ok) {
      const data = await response.json();
      return data.connected;
    }
    return false;
  } catch (error) {
    console.error('Error checking TikTok status:', error);
    return false;
  }
}
```

### Step 2: Handle TikTok Connection

When user wants to connect TikTok or if connection is required:

```javascript
function connectTikTok() {
  // Redirect to backend OAuth endpoint
  window.location.href = '/auth/tiktok/login';
}
```

### Step 3: Handle OAuth Callback

Create a callback page that handles the OAuth return:

```javascript
// On your callback page (e.g., /tiktok-callback)
function handleTikTokCallback() {
  const urlParams = new URLSearchParams(window.location.search);
  const error = urlParams.get('error');
  
  if (error) {
    // Handle error
    showError(`TikTok connection failed: ${error}`);
    return;
  }
  
  // Success - user is redirected here after successful auth
  showSuccess('TikTok account connected successfully!');
  
  // Redirect back to main app
  window.location.href = '/';
}
```

### Step 4: Process URLs with Enhanced Data

Use the enhanced endpoint for better place extraction:

```javascript
async function processUrLWithTikTokAuth(url) {
  const isConnected = await checkTikTokStatus();
  
  if (!isConnected) {
    // Show UI to connect TikTok
    const shouldConnect = confirm('Connect TikTok for better place detection?');
    if (shouldConnect) {
      connectTikTok();
      return;
    }
    // Fall back to regular processing
    return processUrlRegular(url);
  }
  
  try {
    const response = await fetch('/process-url-with-auth', {
      method: 'POST',
      credentials: 'include',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${userToken}`
      },
      body: JSON.stringify({ url })
    });
    
    if (response.status === 401) {
      // Token expired, need to reconnect
      connectTikTok();
      return;
    }
    
    const data = await response.json();
    return data;
  } catch (error) {
    console.error('Error processing URL with auth:', error);
    // Fall back to regular processing
    return processUrlRegular(url);
  }
}
```

### Step 5: Disconnect TikTok

Allow users to disconnect their TikTok account:

```javascript
async function disconnectTikTok() {
  try {
    const response = await fetch('/auth/tiktok/disconnect', {
      method: 'DELETE',
      credentials: 'include',
      headers: {
        'Authorization': `Bearer ${userToken}`
      }
    });
    
    if (response.ok) {
      showSuccess('TikTok account disconnected');
      // Update UI to reflect disconnected state
    }
  } catch (error) {
    console.error('Error disconnecting TikTok:', error);
  }
}
```

## UI Implementation Suggestions

### Connection Status Component

```jsx
function TikTokConnectionStatus({ isConnected, onConnect, onDisconnect }) {
  return (
    <div className="tiktok-status">
      {isConnected ? (
        <div>
          <span className="status-connected">✅ TikTok Connected</span>
          <button onClick={onDisconnect}>Disconnect</button>
        </div>
      ) : (
        <div>
          <span className="status-disconnected">❌ TikTok Not Connected</span>
          <button onClick={onConnect}>Connect TikTok</button>
          <p className="help-text">
            Connect TikTok for more accurate place detection
          </p>
        </div>
      )}
    </div>
  );
}
```

### URL Processing Component

```jsx
function URLProcessor() {
  const [url, setUrl] = useState('');
  const [isProcessing, setIsProcessing] = useState(false);
  const [result, setResult] = useState(null);
  
  const handleSubmit = async (e) => {
    e.preventDefault();
    setIsProcessing(true);
    
    try {
      const data = await processUrLWithTikTokAuth(url);
      setResult(data);
    } catch (error) {
      console.error('Processing failed:', error);
    } finally {
      setIsProcessing(false);
    }
  };
  
  return (
    <form onSubmit={handleSubmit}>
      <input 
        type="url" 
        value={url} 
        onChange={(e) => setUrl(e.target.value)}
        placeholder="Enter TikTok URL"
        required 
      />
      <button type="submit" disabled={isProcessing}>
        {isProcessing ? 'Processing...' : 'Process URL'}
      </button>
      
      {result && (
        <div className="result">
          {result.poi_info ? (
            <div className="enhanced-result">
              <h3>📍 {result.poi_info.name}</h3>
              <p>{result.poi_info.address}</p>
              <span className="badge">Enhanced Data</span>
            </div>
          ) : (
            <div className="basic-result">
              <h3>{result.title}</h3>
              <span className="badge">Basic Data</span>
            </div>
          )}
        </div>
      )}
    </form>
  );
}
```

## Error Handling

Handle these specific error cases:

1. **User not authenticated**: Redirect to login
2. **TikTok not connected**: Show connection prompt
3. **TikTok token expired**: Automatically reconnect
4. **OAuth cancelled**: Show friendly message
5. **Network errors**: Fall back to regular processing

## Benefits of OAuth Integration

When users connect their TikTok account, you get:

- **Exact POI data**: Precise restaurant/place information
- **Coordinates**: Exact latitude/longitude
- **Verified places**: TikTok-verified business information
- **Better accuracy**: No need to parse captions with regex/LLM
